## Practical Programs

### 1. Quadratic Equation Roots

**Objective:** Write a program to find the roots of a quadratic equation.

- Calculate the discriminant.
- Find distinct real roots, equal roots, or complex roots.

### 2. Prime Numbers

**Objective:** Accept an integer and perform the following operations.

- Check whether a number is prime.
- Generate all prime numbers up to n.
- Generate the first n prime numbers.

### 3. Star Pyramid and Reverse Pyramid

**Objective:** Create a pyramid and a reverse pyramid using the `*` character.

- Use loops to print the patterns.
- Accept the number of rows from the user.

### 4. Character Classification

**Objective:** Accept a character and determine its type.

- Identify letters, digits, and special characters.
- Check whether a letter is uppercase or lowercase.
- Display the name of a numeric digit in words.

### 5. String Operations

**Objective:** Perform different operations on a string.

- Find the frequency of a character.
- Replace a character with another character.
- Remove the first occurrence of a character.
- Remove all occurrences of a character.

### 6. Swap First n Characters of Two Strings

**Objective:** Accept two strings and swap their first n characters.

- Preserve the remaining characters.
- Display both modified strings.

### 7. Indices of All Occurrences of a Substring

**Objective:** Write a function that accepts two strings.

- Find all starting indices of the second string in the first.
- Return the indices as a list.
- Return `-1` if the substring is not found.

### 8. Cubes of Even Integers

**Objective:** Create a list of cubes of even integers from an input list.

- Implement the solution using a `for` loop.
- Implement the solution using list comprehension.

### 9. File Handling Operations

**Objective:** Read a text file and perform file operations.

- Count the total number of characters, words, and lines.
- Calculate the frequency of each character using a dictionary.
- Print the words in reverse order.
- Copy even-numbered lines into `File1` and odd-numbered lines into `File2`.

**Note:** Create an `input.txt` file before running this practical.

### 10. Dictionary of Numbers and Their Cubes

**Objective:** Create a dictionary with keys from 1 to 5.

- Use each number as a key.
- Store its cube as the corresponding value.

### 11. Tuple Operations

**Objective:** Perform operations on the tuple:

`(1, 2, 5, 7, 9, 2, 4, 6, 8, 10)`

- Print the two halves on separate lines.
- Create a tuple containing even numbers.
- Concatenate the tuple with `(11, 13, 15)`.
- Find the maximum and minimum values.

### 12. Employee Class

**Objective:** Define an `Employee` class to store employee information.

- Store employee number, name, department, Basic, DA, and HRA.
- Maintain a count of employee objects.
- Calculate the total salary.
- Implement `__del__()` and `__str__()` methods.
- Reject negative salary components.

### 13. Two-Dimensional Point Class

**Objective:** Define a `Point2D` class with x and y coordinates.

- Create point objects.
- Display their coordinates.
- Calculate the distance between two points.

### 14. Three-Dimensional Point and Inheritance

**Objective:** Inherit the `Point2D` class to create a `Point3D` class.

- Add a z-coordinate.
- Override the distance method.
- Calculate the distance between two three-dimensional points.

### 15. Name Validation Using Exceptions

**Objective:** Accept a name from the user and validate it.

- Raise an exception if the name contains digits.
- Raise an exception if the name contains special characters.
- Handle invalid input using exception handling.
